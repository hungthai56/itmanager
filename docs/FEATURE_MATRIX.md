| Cluster | Site switching, tổng hợp vài KPI | Đủ 9 biểu đồ |
| Dashboard | KPI cơ bản, hoạt động gần đây | P&L YTD, biểu đồ dự án nâng cao |
| Users | CRUD, site-access, overrides | UI profile 5 tab chuẩn video |
| Sites | CRUD, site isolation | Multi-database tự động vật lý |
| Settings | Danh mục, mã ca, mẫu checklist | Các danh mục theo scope toàn cụm/từng site |
| Permissions | Ma trận đọc/ghi | Quyền chi tiết từng hành động con |

| Projects | CRUD, progress, milestone text | Task Registry thực thụ |
| Knowledge | Documents / Tutorials nội dung text | Rich text, PDF export, site sharing nâng cao |
